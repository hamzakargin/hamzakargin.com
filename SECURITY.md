# Security Policy

## Supported versions

Only the latest version on the `main` branch, deployed to [hamzakargin.com](https://hamzakargin.com), receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub security advisories](https://github.com/hamzakargin/hamzakargin.com/security/advisories/new) or by email to [hi@hamzakargin.com](mailto:hi@hamzakargin.com).

Include the affected URL or file, steps to reproduce and the impact you expect. You will get a reply within a few days, and a fix as soon as possible once the issue is confirmed.
